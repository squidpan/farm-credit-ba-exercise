# AC-E6-203 Reserve Funding Capacity

## Acceptance Criteria

### AC-203.1 Capacity Available

Given a validated planned issuance,

When funding capacity is available,

Then the required funding capacity is successfully reserved.

---

### AC-203.2 Capacity Unavailable

Given insufficient funding capacity,

When reservation is attempted,

Then the reservation is rejected and the reason is recorded.

---

### AC-203.3 Reservation Complete

Given funding capacity has been reserved,

When reservation processing completes,

Then the planned issuance becomes eligible for security identifier assignment.
