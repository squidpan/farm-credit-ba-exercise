# Farm Credit E6 Approved PlantUML Package

This package contains the approved E6/E6-01 PlantUML diagrams from the 2026-07-21 working session.

Each `.puml` file has a same-named Markdown companion containing:

- the business question answered
- purpose
- interview-ready explanation
- key talking points
- scope boundary
- visual decomposition layer
- related artifacts

The package is structured for placement in a repository under:

`docs/requirements/diagrams/plantuml/e6-propose-and-approve-debt-transaction/`

The original E6-01B package contained two layout variants. The more-spaced variant was retained as the canonical approved source. Both E6-01F control-map variants were retained.
